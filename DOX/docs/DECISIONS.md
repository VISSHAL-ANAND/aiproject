# Architecture Decision Record Log

## ADR-001: Transparent baseline index first
Status: Accepted. A prototype can explain available inputs without pretending to have validated accident probability. Revisit after appropriate data and validation.

## ADR-002: Providers behind service functions
Status: Accepted. Timeouts and provider changes are easier to manage when integrations are isolated.

## ADR-003: Do not bundle fabricated accident records
Status: Accepted. Synthetic records must not be mistaken for ground truth or used to claim accuracy.
