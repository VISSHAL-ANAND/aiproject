# Project Overview

## Problem
Road danger varies by place, time, weather, road geometry, traffic, and historical crashes. Users should select a current road and receive transparent context.

## Goal
Deliver a location-aware educational prototype and, with suitable data, a defensible model for a clearly defined future road-segment risk target.

## Users
College evaluator, project team, and demonstration users.

## Success criteria
App starts from documented commands; GPS/map selection works; weather/road lookup fail gracefully; factors are visible; tests pass; model claims are supported by documented validation.

## Non-goals
Emergency dispatch, guaranteed crash prediction, or safety-critical navigation.
